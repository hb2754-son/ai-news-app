# 뉴스 수집기 새 기능 개발 워크플로우

뉴스 수집기 앱에서 새 기능을 개발할 때 사용하는 명령입니다. 아래 과정을 순서대로 실행합니다.

## 앱 개요
- 필요할 때마다 RSS로 해외 AI 뉴스를 수집해서 카드 형태로 요약 뉴스를 보여주는 앱.
- Claude AI가 한국어로 번역·요약한다.
- 앱을 실행하면 먼저 로그인해야 한다.
- '뉴스 가져오기' 버튼을 클릭하면 뉴스를 가져온다.
- 가져온 뉴스는 자동으로 카테고리별로 분류된다.
- 카테고리에 해당하는 뉴스만 골라서 볼 수 있고, 카테고리는 나중에라도 추가·삭제·수정할 수 있다.
- 뉴스 카드에는 'Notion 저장' 버튼이 있어, 클릭하면 선택한 뉴스를 Notion에 저장한다.

## 뉴스 소스
- TechCrunch AI 섹션
- The Verge AI 섹션

## 기술 스택
- 프레임워크: Next.js
- 로그인: Clerk
- 데이터베이스: Neon, Drizzle ORM
- 번역·요약·카테고리 분류: Claude API
- Notion 저장: Notion MCP 서버

## 실행순서
1. 현재 상태를 확인하고 main 브랜치인지 확인한다.
   main이 아니라면 경고를 주고, main으로 이동할지 물어본다.

2. `$ARGUMENTS`로 받은 이름으로 새 브랜치를 만든다.
   브랜치 이름을 입력받지 못했다면 어떤 기능을 개발할 것인지 물어보고,
   영어 소문자-하이픈 형식으로 브랜치 이름을 제안한다.

3. 브랜치 생성 완료 후 '이제 개발을 시작하세요!'라고 안내한다.
   `CLAUDE.md`를 참고해서 이 프로젝트의 기술 스택과 컨벤션을 다시 한번 알려준다.

4. 사용자가 '완료' 또는 'done'이라고 입력하면
   변경된 파일 목록을 보여주고 커밋 메시지를 자동으로 제안한다.
   사용자가 확인하면 커밋한 뒤 main에 병합한다.

5. 병합 완료 후 작업 내용을 요약해서 보여준다.
